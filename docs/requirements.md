## 認証

### 方式

- メール + パスワードのみ（将来的に 42 API OAuth を追加する可能性あり）
- JWT **Access Token** のみ（Refresh Token なし）
- パスワードは **bcrypt** でハッシュ化（`saltRounds = 10`）

### バリデーション

| 項目 | ルール |
|---|---|
| パスワード | 最小8文字 |
| ユーザー名 | グローバル一意（重複不可）、変更可能 |
| メール | 重複不可 |

### 現在の実装状態

- `auth.service.ts`: signUp / signIn 実装済み、**モック DB（メモリ配列）** を使用中
- Prisma 接続は未完了 → S2 で対応

## ゲーム: ボンバーマン（モジュール #4, #5）

### アーキテクチャ

- **サーバー権威（Server-Authoritative）**
  - ゲーム状態はすべてサーバーで管理
  - クライアントは入力のみ送信し、サーバーから状態を受信して描画
  - チート防止・一貫性保証のため採用

### 仕様

| 項目 | 内容 |
|---|---|
| プレイヤー数 | 2〜4人 |
| ボードサイズ | カスタマイズ可能（ホストが設定） |
| 対戦形式 | インターネット越し（別ネットワーク間） |
| 切断時の挙動 | 即座に最下位（forfeit 扱い） |
| 描画 | Canvas + ゲームループ |
| 入力 | キーボード / タッチ |

### 未確定事項（S3 実装前に決定が必要）

- 爆弾数・爆風範囲のデフォルト値
- タイムリミット
- パワーアップ（あり / なし）
- 勝利条件の詳細

---

## チャット（モジュール #3 の一部）

- **ゲームルーム内限定**（参加中メンバー間のみ）
- グローバルロビーチャット・DM はスコープ外
- Socket.io で配信、メッセージは DB に保存
- チャット画面からフレンドのプロフィールへアクセス可能

---

## 通知（モジュール #7）

- **配信方法**: WebSocket リアルタイム（アプリ内のみ）
- **オフライン時**: DB に保存し、次回ログイン時に未読一覧として表示

### 通知対象イベント

- フレンド申請を受けた
- ゲームに招待された

---

## スコア・ランキング（モジュール #8）

以下の4機能をすべて実装:

1. **個人の勝敗履歴** — 自分の全試合の勝敗を確認できる
2. **グローバルランキング** — 全ユーザーを勝利数等で順位付け
3. **ゲーム別統計** — どのゲームで何勝等、ゲームごとに集計
4. **実績・バッジシステム** — N 勝達成などでバッジ解除
